# NXP-Embedded-Cryptography-Summer-School

In cadrul NXP Summer School – Cryptographic Algorithms in Embedded Systems, am lucrat la implementarea si testarea unor algoritmi criptografici pe platforme embedded, cu accent pe eficienta, consum de resurse si bune practici de securitate. Am analizat scenarii de utilizare si am validat corectitudinea implementarilor prin teste si masuratori, urmarind integrarea lor in aplicatii reale pentru sisteme cu constrangeri.
